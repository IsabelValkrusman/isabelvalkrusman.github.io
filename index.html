ANDROID APP · PUBLISHED ON GOOGLE PLAY

Route 66 Via Baltica: Road Trip

A travel application built for discovering the Via Baltica route across Estonia, Latvia, Lithuania and Poland. The app helps travelers find interesting places and plan their journey with an interactive map.

Users can explore hotels, restaurants, museums, beaches, camping areas, attractions and entertainment venues, save favourite places, add their own locations and keep personal travel notes.

ANDROID APP

Alternative Medicine Research

An educational Android application for researching diseases, alternative medicine and complementary approaches. The app contains a searchable disease database with detailed information, research references and scientific literature. Users can explore topics related to herbs, vitamins, minerals, amino acids, supplements and nutrients, as well as search scientific sources such as PubMed, NCBI and CyberLeninka. Individual PMID numbers can be opened directly to the corresponding PubMed research article.

Built with Kotlin and Jetpack Compose, using Room Database for local data storage and structured disease information. The project includes custom Android UI components, navigation between disease screens, searchable lists, clickable research references and external web links. The application was developed and published on Google Play.

Kotlin Android Jetpack Compose Material 3 Room Database SQLite Coroutines PubMed NCBI CyberLeninka Medical Research

ANDROID APP · AI · FULL-STACK PROJECT

Chic.

Chic. is an AI-powered fashion and personal styling application that combines mobile development, artificial intelligence and image processing.

Users can take a photo of themselves and create a personalized AI avatar or digital doll that resembles their appearance. The avatar is designed to become a virtual representation of the user for experimenting with fashion, outfits and different visual styles.

The app features user profiles, photo posts, captions, image galleries, post editing, deletion and archiving. Users can switch between their own posts and their AI-generated content, creating a social-media-style fashion experience.

The project is built for Android using Kotlin and Jetpack Compose, with local data management and image handling. Camera and gallery functionality allow users to create and upload content directly from the app. The AI functionality is supported by a separate backend responsible for processing images and generating personalized AI content.

Kotlin Jetpack Compose Android AI Computer Vision Image Generation Room Camera Backend Fashion UI/UX

WEB · FULL-STACK · IN DEVELOPMENT

Pickmi

Pickmi is a modern dating platform designed to help users discover new people, connect with others and build meaningful relationships. The platform includes user authentication, profiles, messaging, photo galleries, coins and premium features.

The project is built with React and JavaScript on the frontend, with a Node.js backend and REST API handling authentication, user data and platform functionality. PostgreSQL is used as the main database, hosted with Neon.

The website is hosted through Zone.ee with a custom domain and a separate API subdomain. AI-assisted testing is also used during development to test API endpoints, user flows and different features of the platform.

React JavaScript Node.js REST API PostgreSQL Neon AI Testing Zone Hosting UI/UX
